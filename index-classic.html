Why this exists

I had around thirty projects spread over three disks and two old laptops. Some ran, some didn't, and I couldn't remember which one was the good maze generator. When someone asked “so what have you made?”, I had nothing to show except a file explorer.

So I built a gallery for them. It scans one folder, makes a card for every project, figures out the language and size, and lets me start each one with a single click. Then I kept adding the things I missed: Git, screenshots, presentations, a profile. That's this app.

— the author

What it does

01

Drop projects in a folder. Get a gallery.

Everything inside Documents\Project Gallery becomes a card: name, language, lines of code, last change and a generated banner. Add tags, collections (School, Games, Tools…) and favourites. Drag any other folder onto the window to add it too.

02

Every project gets its own page.

Write a short description, list the main features, add screenshots. The Run button starts the .exe, and you can open the project in Visual Studio, VS Code, CLion or Rider. Press F5 and it becomes a fullscreen presentation — handy at school or a job interview.

03

Git, without opening another program.

Branches, a commit graph, staging, commit, stash, pull and push to GitHub. The cards quietly tell you when something isn't committed or pushed yet, or when a project hasn't been touched in a month.

  • Switch branches and jump between commits
  • Commit + push in one step
  • Clone a repository straight into the gallery
  • Warnings for uncommitted / unpushed work
04

A profile that says who made all this.

Your name, photo, what you do, the tech you use and your links. The profile page adds up your projects, lines of code, languages and the programs you run the most.

Also in there

  • Light, dark or follow Windows
  • 14 languages, English by default
  • Command palette on Ctrl+K
  • Tracks how long each program ran
  • README.md generator
  • Tray icon with recent projects
  • Automatic backups + export/import
  • Delete to Recycle Bin or for good

Pro

For when you want to show it to people.

Pro is a one-time purchase. It adds the parts that take your projects out of your computer — and a few that are just fun.

  • Portfolio website. One click exports a static site with your profile and every project. Upload it to GitHub Pages and send the link.
  • PDF presentations. Each slide becomes a page.
  • Build from the gallery. MSBuild and CMake, with errors listed.
  • Automatic screenshots. It starts your program and photographs the window.
  • GitHub. Stars, issues, and creating a repo for a project.
  • Your colours. Accent colour, styles and backgrounds — including your own image.
  • A year of activity. Commit heatmap across all projects, streaks, a weekly goal and 12 achievements.

Questions

Is the free version actually free?

Yes. No time limit, no watermark, no nagging. Pro only adds extra features on top.

Does it upload my code anywhere?

No. Everything stays on your disk. The app only goes online if you ask it to: Git push/pull, GitHub features with your own token, and the update check (which you can turn off).

Windows says “unknown publisher” when I install it.

That's SmartScreen. The installer isn't signed with a paid certificate yet. Click More info → Run anyway. If you'd rather not, that's completely fair — wait for a signed release.

Mac or Linux?

Not right now. It's written in C++ with DirectX 11, so it's Windows only.

What kind of projects does it understand?

Anything in a folder. It finds Visual Studio solutions, built executables and Git repositories on its own, and counts lines of code for the common languages. If it can't find the .exe, you point it at one.
