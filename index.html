What it does

01

Drop projects in a folder. Get a gallery.

Everything inside Documents\Project Gallery becomes a card: name, language, lines of code, last change and a generated banner. Add tags, collections (School, Games, Tools…) and favourites. Drag any other folder onto the window to add it too. A short wizard sets it up on the first run, and a scan cache opens a gallery of 60 projects in under a second.

02

Every project gets its own page.

Write a short description, list the main features, add screenshots. Run starts the .exe, Open in editor opens Visual Studio, VS Code, CLion or Rider, and the ⋯ menu holds only the actions that make sense for that project. Press F5 and it becomes a fullscreen presentation — handy at school or a job interview.

03

17 themes. Each one is its own world.

Calm Graphite, Paper and Contrast, or concept themes like Terminal, Synthwave, Blueprint, Notebook, Pixel, Windows 95, Comic and Deep sea. Each has its own fonts, cards, banners, sounds, button animations and screen transition — and every theme has a dark and a light mode. Pick your accent colour; Pro recolours a whole theme from one colour.

04

Git, without opening another program.

Branches, a commit graph, staging, commit, stash, pull and push to GitHub. The cards quietly tell you when something isn't committed or pushed yet, or when a project hasn't been touched in a month.

05

A profile that says who made all this.

Your name, photo, what you do, the tech you use and your links. The profile page adds up your projects, lines of code, languages and the programs you run the most.

06

Fix the bug without leaving the gallery.

The ‹› Code tab is a small code editor: a file tree, tabs, syntax highlighting for C++, Python, web and more, find & replace and Ctrl+S. It remembers which files you had open. Pro adds Ctrl+P, search across the whole project, build errors marked right in the code, F5 to build and run, and a split view.

07

Know where you left off.

Every project shows your last commit, the files you were editing and a note for next time. The History tab puts commits, launches and finished tasks on one timeline, the gallery reminds you of projects you've forgotten, and “Working on it” times your sessions (it pauses when you walk away). Tasks and a quick health check are in there too; Pro adds kanban, Pomodoro and a weekly report.

08

One search for everything: Ctrl+K.

Projects, commands, settings, tasks and files, all from one box. Type “portfolio” and you get the project, the export command and the setting. Pro also searches inside the files of every project.

09

Get your disk space back.

The disk cleaner finds build, x64, .vs, node_modules and other output folders across all projects and shows what it found first. Nothing is deleted until you confirm, everything goes to the Recycle Bin, and folders with files tracked in Git are skipped. Pro adds automatic daily backups of changed projects.

10

Start new things, ship finished ones.

Ctrl+N starts a project from a template — a C++ console app, a raylib game or a Python script, ready to build. When it's done, export a clean ZIP, make a share card for Discord or LinkedIn, and add your own one-click actions. Pro adds SFML, ImGui and web templates, GitHub releases, a public project link, version compare with a generated changelog, and continuous sync.

Questions

Is the free version actually free?

Yes. No time limit, no watermark, no nagging. Pro only adds extra features on top.

Does it upload my code anywhere?

No. Everything stays on your disk. The app only goes online if you ask it to: Git push/pull, GitHub features with your own token, the update check (which you can turn off) and, with Pro, a licence check every few days that sends only your key and an anonymous computer ID.

On how many computers can I use Pro?

Up to 3 of your own at the same time — say a desktop, a laptop and the school PC. To move Pro to another one, click Deactivate on this computer on the old one. Lost access to an old PC? Write to me and I'll free the slot.

Does Pro need the internet?

Only to activate. After that it keeps working offline; the app quietly renews the activation when you're online, and it stays valid for 30 days without a connection.

How do updates work?

One click. The app checks for a new version when it starts; click Update and it simply replaces its own .exe and restarts — no installer to click through. Your projects, notes and settings stay as they are. 1.x updates are free for Pro owners.

How many themes are there? Is there a dark mode?

17. Free has Graphite, Paper, Contrast and the Terminal concept theme, plus the Legacy Studio and Minimal. Pro adds the concept themes Synthwave, Blueprint, Notebook, Pixel, Brutal, Windows 95, Comic and Deep sea, and the Legacy Terminal, Paper and Synthwave. Every theme has a dark and a light mode — pick one or follow Windows.

Windows says “unknown publisher” when I install it.

That's SmartScreen. The installer isn't signed with a paid certificate yet. Click More info → Run anyway. If you'd rather not, that's completely fair — wait for a signed release.

Mac or Linux?

Not right now. It's written in C++ with DirectX 11, so it's Windows only.

What kind of projects does it understand?

Anything in a folder. It finds Visual Studio solutions, built executables and Git repositories on its own, and counts lines of code for the common languages. If it can't find the .exe, you point it at one.

How do I get Pro during the beta?

Copy your Computer ID in the app (Ctrl+K → About & license → Copy) and send it to e-mail. You'll get an activation code for that computer. Full guide →

Does it work with Unity, Python, web or game-engine projects?

Yes — any folder is a project. Visual Studio, CMake and Git projects get extra help (run, build, commits), everything else still gets a card, notes, tasks and a launcher.
